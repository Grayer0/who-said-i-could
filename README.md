# 谁允许我买的？ · Who Said I Could

> 花钱之前，先找个人批一下。
> Ask a friend before you buy it.

**介绍页 / Live page → https://grayer0.github.io/who-said-i-could/**

一个微信小程序：把一次冲动消费变成一份需要陈述理由、等待回复的**审批申请**。
一条申请可以同时发给多位好友，由**多数意见**决定结果——批准、驳回，或者「再想想」。

A WeChat Mini Program that turns an impulse purchase into an **approval request**.
You state your case, your friends vote, and the majority decides — approve, reject,
or "think it over".

---

### 它是怎么工作的 · How it works

| | |
| --- | --- |
| 提交申请 · Submit | 想买什么、多少钱、**为什么**——理由是必填的 |
| 分享给好友 · Share | 打开链接就能表态，不用注册，人数不限 |
| 逐一表态 · Vote | 批准 / 驳回 / 再想想，每条意见底下都能讨论 |
| 多数决 · Decide | 票数变了结果跟着变，平票计为「再想想」 |

无广告、无第三方统计，所有申请记录只保存在使用者自己的账号下。

No ads, no third-party analytics — every record stays in the owner's own account.
